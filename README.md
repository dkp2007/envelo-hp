## ✨ Features

### 💰 Envelope Budgeting
Create budget envelopes for Rent, Food, Entertainment, Utilities, and more. Track spending against each envelope and see exactly where your money goes.

### 📊 Interactive Analytics
Five chart types — Doughnut, Polar Area, Bar, Line, and Radar — with time range filters (1M / 3M / 6M / All). Includes spending trends, expense breakdowns, category comparisons, and savings rate tracking.

### 🛡️ Budget Stress Test
Simulate real-world financial shocks — medical expenses, income reduction, job loss, rent increases — and see how resilient your budget is. AI-powered analysis gives personalized recovery plans and quick wins.

### 🤖 AI Financial Plan
Answer a few questions about your income, expenses, and goals. Get a personalized savings and expenditure plan generated by AI (Groq / LLaMA 3.3).

### 📈 Reports & Export
Monthly income vs. expenses, budget vs. actual, top spending categories, and key metrics — all exportable as **PDF** or **Excel** with multiple sheets.

### 🎯 Savings Goals
Set targets with deadlines, track progress with visual indicators, and stay motivated watching your savings grow.

### 🧾 Bill Upload
Drag-and-drop receipt/bill upload on the Add Expense page. Supports JPG, PNG, and PDF with instant preview. (Frontend only — backend processing coming soon.)

### ⚙️ Full Settings
Personal info, notification preferences, language, timezone, currency, and date format — all persisted to Supabase.

### 🏠 Public Landing Page
Animated splash intro, feature showcase, how-it-works flow, and legal pages (Privacy Policy, Terms of Service) — all accessible without authentication.

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | Vue 3 (Composition API), Vue Router, Pinia |
| **Build Tool** | Vite 8 |
| **Styling** | Custom CSS with CSS variables (no UI framework) |
| **Charts** | Chart.js + vue-chartjs |
| **PDF Export** | jsPDF + jspdf-autotable |
| **Excel Export** | SheetJS (xlsx) |
| **Backend** | Supabase (Auth, PostgreSQL, RLS) |
| **AI** | Groq SDK (LLaMA 3.3 70B) |
| **Linting** | ESLint + oxlint + Prettier |


---

## 🔒 Security

- **Row Level Security (RLS)** enabled on all Supabase tables — users can only access their own data
- **Environment variables** for all API keys (`.env` is gitignored)
- **No secrets committed** — `.env`, `.freebuff/`, and `supabase/.temp/` are excluded from version control
